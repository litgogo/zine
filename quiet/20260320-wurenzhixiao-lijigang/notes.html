逻辑骨架

P01　每个人都在自己的取景框里

问题：为什么一个把求真放在第一位的人，先说每个人都是错的？

论点：他的世界观先立一个前提：真实的世界高维存在，所有人看到的只是投影。

他认为真实本体存在，而且维度很高。不同学科、不同人的看法，是它投下的片面投影。所以说每个人都是错的，这是从前提推出来的结论，不是谦辞。

这个前提带来两个习惯。一是收集不同的取景框，用来反推本体；二是把观点和自我分开。有人能用更好的取景框驳倒他，他当作收获。

代价是这套判断不可验证。真实本体存在属于信念，不是结论，他自己把这一层说在前面。

依据：每个人都有固化的取景框，说跟某人聊不来，说的其实是自己的取景框。（李继刚，04:49）、真实本体存在而且维度很高，不同学科、不同人的看法只是它投下的片面投影。（李继刚，05:47）、他把观点和自我分开，如果有人能用更好的取景框驳倒他，他会感激。（李继刚，06:32）

P02　稀缺性换了三个位置

问题：三个世界凭什么分开？

论点：三个世界的区别不在技术，在稀缺性从哪来。

原子世界稀缺于位置。山顶的水、学区房、商铺，贵的不是劳动，是位置。缆车通了，水照样贵。

比特世界把空间拿掉，任意两点距离为零，稀缺转向注意力。谁抢到注意力，谁赚钱。

向量世界把时间拿掉。他把大模型看成全人类知识烧成的一块晶体，几千年时间压在里面，对话等于直接调用。体感是离开屏幕要使劲把自己拔出来。

依据：原子世界的稀缺来自位置。（李继刚，31:51）、信息极大丰富之后，注意力成为唯一瓶颈。（李继刚，35:18）、AI 产品看起来像互联网，内核是一次世界构建，把时间拿掉。（李继刚，37:06）、大模型是全人类知识烧成的一块晶体。（李继刚，38:04）

P03　承认被碾压，仍然要发声

问题：当模型写得比自己好，还要不要发声？

论点：孟岩的表达欲被抽空了，李继刚的答案是发出声音本身就是存在。

孟岩说很久没发微博和小红书，下意识觉得自己什么都不懂。李继刚说他有同感，但这个问题需要被解决。

他的理由不是懂得更多，而是起心动念。不表达，在某种程度上就不存在。

《AlphaGo》里 AI 打开围棋的大门，里面空无一人，职业棋手找不到意义。他说各行各业都会陆续遇到，只是分布不均。

依据：副作用是很久没发微博和小红书，没有表达欲望。（孟岩，45:40）、表达不是教别人，是当下的起心动念要说给世界听。（李继刚，46:16）、《AlphaGo》里 AI 打开围棋的大门，里面空无一人。（孟岩，47:36）

P04　整包外包与先立判断

问题：同一个模型，为什么差距会变成负数与乘法？

论点：AI 只放大原本存在的意志，它不生产意志。

第一种姿态把任务整包丢给模型。结果是六十分及格，人退成复制粘贴的通道，思考比没有 AI 时更停滞。

第二种先自己写几十字初稿和框架，再让模型挑问题、把根基打深。他说 AI 是放大器，放大的是你的意志性。

分工上他的口径是脑交给模型，心交给人。孟岩在招聘里试过：近百份简历交给 agent，面试问题交给 agent，但面谈时的在场感 agent 给不了。

依据：第一种姿态把任务整包丢给 AI，人退成复制粘贴的通道。（李继刚，01:08:36）、AI 是放大器，放大的是意志性。（李继刚，01:10:13）、脑交给模型，心交给人。（李继刚，01:17:29）

P05　互联网是一张网，AI 是一口井

问题：AI 公司还是不是互联网公司？

论点：网的胜负在节点数量，井的胜负在对一个人的理解深度。

互联网的底层是马太效应，网的价值随节点数的平方走，谁先过临界值谁起飞。

井的深度是他说的 context：把一个人的 memory 和 soul 刻画好。用户画像是算力不足时的替代品，AI 才能一人一面。

商业也跟着变。深度定制到极致是信任，插广告会伤根基；商品进推荐库收入库费；理解足够深时只给一个答案，第二名没有价值。

依据：互联网的底层规律只有一个，马太效应。（李继刚，50:26）、AI 更像一口井。（李继刚，01:20:34）、井的深度是对 context 的理解，即把 memory 和 soul 刻画好。（李继刚，01:21:39）、商品入推荐库可收入库费；理解足够深时只给一个答案。（李继刚，01:29:05）

P06　公司买的东西从人脑变成 token

问题：公司还需要人吗？

论点：招人是为了买人脑里的知识与经验，当 token 更便宜，替换没有选择余地。

科层制、激励机制、目标管理，都是为传递信息与协同而生。他推演到极致：一个公司只有一个创始人，其他全是 AI。

两百美元的 token 产出超过月薪一万的人。竞争之下，老板没得选。

他给这个时代出的题不是德鲁克那道。德鲁克回答上万人如何协作，现在要回答一个人如何管理一万个 agents。agents 没有私心，管理的哲学不一样。他还说模型之战不是商战，是国战。

依据：公司招人是为了买人脑里的知识技能经验。（李继刚，02:28:48）、两百刀的 token 产出超过月薪一万的人。（李继刚，02:30:21）、推演到极致，一个公司只有一个创始人，其他全是 AI。（李继刚，02:31:42）、这个时代需要回答一个人如何管理一万个 agents。（李继刚，02:32:17）

P07　起点、路径、终点

问题：提示词到底在写给什么？

论点：模型极擅长插值，你不指定路径，它就用自洽的方式填满。

他的拆法是三段：起点、方向、路径。给一个身份角色，等于在智能之海里指定一个位置；技能和思考方式只是把位置扎得更鲜明。

只给起点和终点，中间那段不可控。同一份现金流折现，30 年按 7% 还是 9%，结果差几百倍，决策方向相反。

他也说清边界：能显性化的只是形状，参数取决于人的认知经营程度。元提示词生成的东西带匠气，他后来靠高信息密度加多轮对话绕开。

依据：指定身份角色等于在智能之海里指定一个位置。（李继刚，01:59:54）、只给起点和终点，插值过程不可控。（李继刚，02:01:36）、科学是可测量的部分，艺术是只能靠判断的部分。（李继刚，02:04:05）、元提示词生成的东西带匠气。（李继刚，02:06:13）

P08　五百人、十个槽位、五个人

问题：信息越多，人为什么越要设限？

论点：开放的实际结果是混乱，信号被淹没，他用硬性限额制造秩序。

微信好友从四千多删到五百，朋友圈只看五个人。公众号只留十个槽位，要关注第十一个就要先删一个。

读书用杠铃：只读经典和最新论文，中间的畅销书基本不读。标准很直白，一百年后还在的书，经得起时间。

他说下一层的约束带来上一层的自由，两者错位。孟岩提醒这可能是控制欲，他没有否认，只说开放的结果是混乱。

依据：微信好友从四千多删到五百。（李继刚，02:55:01）、公众号只留十个槽位，关注第十一个先删一个。（李继刚，02:58:34）、下一层的约束带来上一层的自由。（李继刚，03:01:07）、读书也用杠铃策略，只读经典和最新论文。（李继刚，01:51:58）

P09　干的部分交给 AI，湿的部分只能线下

问题：语言交给模型之后，人的哪一部分留下来？

论点：精确与效率可以外包，人味只能来自小规模的真实相处。

他说过去的秩序把人当耗材，情绪与能量的那部分被排出去。现在反过来，湿的变成稀缺。

所以他定期组小局，三五人到七八人。人一多就进入表演人格，规模要刻意控制。播客他不听，理由是太长，而且属于湿的那一类，湿的必须线下见面。

语言被 AI 化之后，意图表达更准，人味要放到另一个地方去补。

依据：干状态是把人当耗材，湿状态是情绪与能量。（李继刚，57:06）、语言被 AI 化之后，人味要放到线下。（李继刚，02:52:45）、定期组小局，三五人到七八人，人多就进入表演人格。（李继刚，02:53:57）

P10　水的教育，火的教育

问题：需求端消失之后，教育要教什么？

论点：知识灌注随需求端崩塌而失效，出口是找到长板再用 AI 放大。

过去的教育像水，往脑子里灌，考核灌进去多少。API 像水管直接插进脑子，企业当然选它，纯背诵没有意义。

火的教育找那根火柴。一个人有多个维度，总有一维是天赋加热情，随手做就比别人努力做得好。

他知道社会惯性大，等不到新教育落地，所以给过渡方案：白天水的教育，晚上火的教育。前提是家长先退出排名体系，这一步比方法难。

依据：过去的教育像水，把知识灌进脑子。（李继刚，03:16:15）、纯背诵已无意义。（李继刚，03:17:05）、有一个维度是天赋加热情所在。（李继刚，03:18:10）、可行方案是白天水的教育、晚上火的教育。（李继刚，03:19:30）

P11　抓不变，抓稀缺，然后接受自己的人味

问题：如果只带走两句话，是哪两句？

论点：他的自处方法不复杂：先定住什么不变，再看稀缺性搬到哪里，剩下的交给线下。

两块压舱石：什么是不变的；稀缺性转移到哪里了。内核保守，外围激进。

还有一句下限思维：八成算力盯最差的情况，能接受之后，事情发生在这之上。他也说，因恐惧而做的决策，无论做还是不做，结果大概率不会是好事。

结尾是孟岩做的实验：把李继刚的幻灯片、两人上次的逐字稿、自己几百篇语料交给 AI，只问它最想听两人聊什么。AI 的判词是两个人从完全相反的方向走，一个从理性的尽头走向心灵，一个从心灵出发走向结构，最后汇集在同一个问题上。

依据：只长期盯两个问题：什么没变，稀缺性转移到哪。（李继刚，02:42:41）、因恐惧而做的决策，结果大概率不会是好事。（李继刚，02:45:31）、AI 判词：李继刚是从理性的尽头走向心灵的人。（孟岩，03:23:08）、你们俩从完全相反的方向走。（孟岩，03:24:03）
